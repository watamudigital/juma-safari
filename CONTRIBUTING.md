# Collaborare a Juma Safari

Il sito è una demo. Prima di usare dati reali, chiedere conferma al gestore e non pubblicare numeri privati, foto o informazioni commerciali senza autorizzazione.

1. Crea un branch (es. `content/descrizioni-tsavo`).
2. Modifica il testo in `index.html` senza eliminare la dicitura demo o le protezioni `noindex`.
3. Prova la pagina in un browser, anche da smartphone.
4. Apri una pull request verso `main`, descrivi la modifica e allega una schermata.
5. Aspetta una revisione prima del merge; non lavorare direttamente su `main` se sei un collaboratore in formazione.

Per i messaggi di commit usa titoli chiari: `docs: corregge testo Tsavo` o `feat: aggiunge FAQ`.
